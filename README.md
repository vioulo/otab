#### 0.3.0 26-04-27 22
1. 升级扩展规范至 **Manifest V3**（Gecko min: 109.0+）
2. 整合 Tmpin 图钉插件核心功能（工具栏弹窗、快捷分组、右键随时钉住）
3. 限制图钉链接最多 60 条，分组最多 6 组，配额徽标实时提示
4. 新标签页侧边栏置顶集成【📌 图钉板】，支持新标签页大看板浏览与右键移除
5. 图标加载改为目标源站直接获取（`${origin}/favicon.ico`），彻底脱离第三方中转
6. 新增图标加载异常时的优雅降级（首字母彩色文字徽章）
7. 修复窗口缩放时边缘检测失准 Bug，移除遗留无效的 jQuery 标签
