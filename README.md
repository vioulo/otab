# Otab

<a href="https://addons.mozilla.org/zh-CN/firefox/addon/otabx/" style="font-size:18px;">🔥 Firefox 扩展商店地址 (AMO)</a>

Otab 是一款专为 Firefox 设计的极简现代新标签页与常用网页图钉管理扩展。它直接基于浏览器的原生书签栏构建沉浸式看板，并无缝融合了轻量高效的网页暂存图钉板，实现“**随手暂存采集 ➔ 新标签页沉浸消费**”的完整闭环。

---

## ✨ 核心特性

### 📌 随身图钉与暂存 (Quick Pin)
- **工具栏弹出窗**：点击浏览器右上角图标，随时随地查看、检索与管理图钉。
- **右键一键暂存**：浏览任何网页或超链接时，通过右键上下文菜单一键直接“钉住此页面到 Otab”。
- **精炼配额控制**：全量上限 60 条图钉链接、最多 6 个分组，保持日常面板的轻量克制。
- **分组管理与批量启动**：自由创建分组、拖拽排序、组内与跨组移动，并支持一键在后台批量打开整组所有链接。

### 🔖 新标签页书签看板 (New Tab Workspace)
- **原生书签同步**：无缝映射 Firefox 原生书签栏（Bookmarks Toolbar），无需额外账号，零导入导出负担。
- **置顶【📌 图钉板】**：新标签页侧边栏首项常驻图钉板，大画板沉浸式浏览图钉内容，支持直接右键删除。
- **智能“缓存区”**：未归入任何文件夹的根目录零散书签自动聚合成虚拟缓存区，告别杂乱。
- **视觉数据量化**：文件夹与图钉板附带大字号镂空数字计数，悬停渐变动效，收纳数量一目了然。

### 🎨 极致极简与隐私友好
- **源站 Favicon 直连**：链接图标直接从站点根目录（`/favicon.ico`）请求加载，彻底脱离第三方中间商，安全且保护隐私。
- **优雅容错降级**：无根目录图标或加载失败时自动平滑回退为站名首字母文字徽章，拒绝破损裂图。
- **原生深色模式**：随系统与浏览器自动平滑切换亮色与暗色模式。
- **高度定制化**：支持侧边栏左右位置切换、网格/流式布局列数即时增减、支持自定义 CSS 注入。
- **现代规范**：采用 Firefox **Manifest V3** 扩展标准规范构建。
